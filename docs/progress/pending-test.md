# 待测试

## 独立二开基础分支

- 本机设置 `CANVAS_BIND_HOST=127.0.0.1`，确认仅监听 loopback；设置 `CANVAS_DISABLE_PROMPT_SYNC=true`，确认不创建外部提示词抓取定时器。
- `web/` 放在另一个项目目录下时，确认构建生成自己的 `.next/standalone/server.js`，复制 public/static 后可打开画布。
- 未登录时新建文本节点，刷新、返回库并重开，确认浏览器本地恢复；登录后用全新浏览器登录同账号，首次进入即恢复云端画布，无需手动刷新。
- 1440×900 和 1280×720 桌面查看画布库及编辑器；本轮不包含真实模型生成或20人容量验收。
